```bash

pip install -r requirements.txt
```

Open notebooks in VS Code or run `jupyter notebook` in your terminal.

## 📈 Key Findings

- Descriptive and outlier analysis (NumPy/Pandas) confirmed which process variables show the most variability and where statistical outliers cluster.
- Shift performance comparison (early/late/night) found no meaningful variance between shifts — expected given the dataset's synthetic generation, but a useful sanity check on the analysis method itself.
- Visualization phase planned next to turn these findings into trend and control charts.
